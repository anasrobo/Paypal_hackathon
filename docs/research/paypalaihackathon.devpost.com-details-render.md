#### About Render

Render is an intuitive cloud platform for developers who want to ship production-grade apps and agents without managing infrastructure. Push your code to instantly provision web services, databases, workflows, and long-lived workers with automatic networking. Render keeps you focused on your product as traffic grows through automatic scaling, zero-downtime deploys, and data redundancy.

[**Start building with $50 of Render credits here!**](https://credits-portal-mmdm.onrender.com/claim/paypal-ai-hackathon)

#### How to use Render

Deploy your project on Render and use [Render Workflows](https://render.com/docs/workflows), an orchestration and execution engine for distributed tasks, to coordinate AI agents, background jobs, and data pipelines. Define tasks as standard functions using Render's lightweight SDK and dispatch them across hundreds of concurrent instances.
