#### AG Grid

[AG Grid](http://ag-grid.com/) is the company behind the data grid, charts, and dashboards powering over half of the Fortune 500.

[AG Studio](https://www.ag-grid.com/studio/) from AG Grid is an embedded analytics library (or, as some prefer to say, self-serve dashboard component). It brings dashboards, charts, and grids, together in one component. Developers set the guardrails once. Analysts and end users build and change dashboards inside them without having to write code. It comes with a built-in data engine, cross-filtering, and the [Studio Agent Framework](https://www.ag-grid.com/blog/introducing-the-ag-studio-agent-framework/), so agents can build, query, and edit dashboards for you and alongside you.

##### Best Use of AG Grid

This award covers both what your dashboard looks like and how you build it.

Show us polish: custom widgets, theming, and layout tools, not just AG Grid or AG Charts on their own. Take Studio Agent Framework for a spin: a custom agent talking to Studio's built-in agents, or a swapped-in harness.

##### Project ideas

This is not a list of our expectations! Just something for you to start:

- **Storefront analytics** for Central Perk (Friends), Schrute Farms (The Office), Luke's Diner (The Gilmore Girls): revenue-by-product widgets, refund rate tiles, geographic sales maps

- **Anomaly-alert agent:** monitors transaction streams and auto-builds widgets flagging suspicious refund spikes or failed payments

- **Nonprofit donation dashboard:**live PayPal donation feed, donor leaderboard, campaign progress bars

- **Natural-language finance agent:** "show PayPal revenue by customer segment this month" generates a live widget

- **Nudge-bot:** a gentle-reminder agent that reads unpaid invoices and drafts friendly nudges ("hey, just a heads-up!") instead of demands, with a widget showing who still owes what, styled like a friendly scoreboard rather than a collections report.
