#### ABOUT CHANNEL3

Channel3 lets anyone build an AI shopping experience in an afternoon. One API returns clean, normalized product data – titles, images, prices, variants, availability, and buy links – across 100M+ products from 25,000+ retailers. No scraping, no retailer feeds, no data cleanup. People use Channel3 to build shopping agents, personalized gift finders, AI stylists, product comparison tools and conversational search for retail sites.

##### Channel3

Your project may use the Channel3 API or our MCP server as a meaningful part of the product experience — search, product enrichment or recommendations.  Projects that only reference Channel3 without calling it will not meet this requirement.

- **Eligibility:** API keys are available to all hackathon participants.

- **Getting started:** Sign up at [https://trychannel3.com/developers](https://trychannel3.com/developers), grab your key from the dashboard, and you're live. No credit card required. Each hackathon key includes 20,000 free API credits with promo code **PAYPAL-HACKATHON-2026**, good for 20,000 product searches.

- **Running out of credits:** Your app stays live and your key stays active. Message us in the [**#channel3 hackathon Discord channel**](https://discord.gg/sJ2G6DyvSK) and we'll top you up, don't let credits block your demo.
